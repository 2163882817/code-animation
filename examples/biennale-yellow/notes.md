# Biennale Yellow · 参考片说明

## Beat sheet

| 时间 | 画面 | 实现 |
|---|---|---|
| 0.0–0.8 | 外框与两道横线从四角向中间生长 | `frameLines()`，`easeInOut` |
| 0.35–1.9 | 太阳从下方 300px 升起，光晕 0→1 | `sun()`，`easeOut` |
| 0.9–2.4 | 两行标题上浮 24px，字距 +20→−4 | `trackedText()`，逐字绘制 |
| 1.9–2.7 | 页眉、页脚淡入 | 全局 alpha |
| 2.7–4.0 | 刻度环 1°/s，光晕缓慢呼吸 | `ctx.rotate(t * π/180)` + `sin(t*0.9)` |
| 4.0–4.8 | 小注 + 细线淡入（第二拍，填补下半部） | `trackedText()` + 线段生长 |
| 4.8–7.4 | 全部元素静置微动，刻度环继续转 | — |
| 7.4–8.0 | 整体淡出到纸色，循环 | 纸色覆盖，`easeInOut` |

## 关键决策

1. **纸纹缓存**：5000 个 1–3px 方点只在启动时生成一次，之后 `drawImage`。每帧重画会掉到 10fps 以下。
2. **字距手写**：不用 `ctx.letterSpacing`（浏览器差异大），用 `trackedText()` 逐字定位；`w1/w2` 顺便用来检查标题是否压到刻度环（右端 < 948）。
3. **太阳和刻度环同一函数**：升起时环跟着走，避免"太阳到了环才出现"的割裂。
4. **前 0.3 秒**：外框从 1.2% 的角标开始画，第 1 帧就有四个小角标和两道横线的端点，不是一张空纸；0.3s 时框线已经走了约 1/4。
5. **中段第二拍**：4.0s 让小注和细线出现，把 4.7 秒的静止切成两段；同时光晕与实心圆做 0.3–0.6% 的呼吸，暂停时也"活着"。
6. **确定性**：唯一的随机是纸纹，固定种子 `20261029`；`draw(t)` 里没有任何累积状态。同一 `t` 两次截图逐像素一致。

- 最强：太阳升起 + 字距收紧同时发生，两个动作互相掩护；4s 的小注把节奏切成两段。
- 最弱：4.8–7.4 仍然偏静，只靠刻度环和光晕呼吸撑着；真实项目里应该再放一层信息。

## 怎么改成你的

1. 改标题：`STYLE` / `Atlas`（两行，第二行斜体）。
2. 改页眉：`THE 341 · CODE ANIMATION SERIES` → 你的系列名；`N° 01` → 期号。
3. 改页脚：中文一句话 + 右侧编号/年份。
4. 改色：只改 `C.paper / C.ink / C.sun` 三个值；不要加第四个强调色。
5. 改时长：`CFG.duration`（同时改淡出起点 `seg(7.4, 8.0, t)`）。
6. 出静帧确认标题没有压到刻度环（控制台会 warning）。
