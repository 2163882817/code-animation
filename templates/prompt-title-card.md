# 可直接粘贴的提示词 · 8 秒标题卡

> 用法：把 `{{ }}` 全部替换成你的内容，整段发给任何能写代码的模型（Claude / GPT / DeepSeek）。
> 生成后把代码存成 `index.html`，用 `scripts/check.mjs` 体检，再用 `scripts/render.mjs` 出片。
> 默认风格：H1 Biennale Yellow（羊皮纸 + 太阳 + 衬线大字）。换风格只改「颜色/字体/版面」三段。

```text
你是一位前端动效工程师 + 美术指导。请写一个完整的 index.html：
只用原生 HTML + JavaScript + Canvas 2D，不要任何外部库、字体文件或图片。

## 内容
- 大标题（两行）：{{STYLE}} / {{Atlas}}（第二行斜体）
- 页眉左：{{THE 341 · CODE ANIMATION SERIES}}；页眉右：{{N° 01}}
- 页脚左（中文）：{{三百四十一种风格，用代码呈现}}
- 页脚右：{{2026 · STUDIO}}
- 总时长：{{8}} 秒

## 输出契约（必须照做）
1. 只输出一个 html 代码块，不要解释。代码必须完整可运行：不要省略号，不要"其余同上"。
2. canvas 固定 1920×1080，用 CSS 等比缩放居中，多出来的是黑边。
3. 画面只由 draw(t) 决定（t 是秒）。不要用 Math.random / Date.now；
   随机用带种子的 mulberry32(seed)，只在初始化时生成一次。
4. 默认循环；空格暂停；URL 带 ?t=3.2 时只画第 3.2 秒那一帧。

## 颜色（只准用这些）
- 纸 #F2E9D2；纸纹：5000 个 1–3px 方点，一半 #8C7A55、一半 #FFFAF0，透明度 0.045–0.095，
  只画一次，缓存到离屏 canvas。
- 墨 #1D2A68；太阳 #F6C23E（全片唯一的强调色）。
- 线宽 1.6–1.8px。

## 字体
font-family: Georgia, "Times New Roman", "Noto Serif SC", "Songti SC", SimSun, serif
大标题 214px，字距 −4px；页眉 26px 全大写，字距 6px；页脚中文 34px。

## 版面（1920×1080）
- 外框 strokeRect(64, 64, 1792, 952)；两条横线 y=148 / 932，x 从 64 到 1856。
- 太阳圆心 (1380, 470)：光晕半径 20→560；实心圆半径 250；
  三道同心圈 250 / 330 / 410；刻度环 120 条（410→421，每 5 条到 432）。
- 大标题左对齐 x=100，第一行基线 y=560，第二行 y=770；标题右端 < 948。
- 页眉基线 y=118（左 x=104，右 x=1650）；页脚基线 y=980（左 x=104，右对齐 x=1816）。

## 时间轴（秒）
0–0.8 外框从四角向中间画出来（ease-in-out）
0.35–1.9 太阳从下方 300px 升起（ease-out），光晕透明度 0→1
0.9–2.4 两行标题上浮 24px、淡入，字距 +20→−4
1.9–2.7 页眉页脚淡入
2.7–{{7.4}} 刻度环 1°/s 慢转，其余静置微动
{{7.4}}–{{8.0}} 整体淡出到纸色，循环

## 不要
渐变色块、阴影、圆角卡片、第二种强调色、无衬线大标题、发光、粒子、3D。

## 写完后自己过一遍（不要输出）
- 全片是否只有 #F6C23E 一个强调色？
- 标题是否碰到刻度环？
- t=0 是否几乎没有信息？t=总时长−0.1 时所有元素都在？
- 同一个 t 刷新两次，画面是否一模一样？
```
