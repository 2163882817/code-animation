# 可直接粘贴的提示词 · 30 秒白板讲解

> 适合：概念解释、课程切片、工具教学、B 站/视频号知识区。
> 风格来源：M1 白板手绘 + L22 白板讲解 + M23 五幕结构。
> 把 `{{ }}` 换成你的内容；生成后存 `index.html`，先出静帧再渲染。

```text
你是一位擅长白板手绘讲解的前端动效工程师。请写一个完整的 index.html：
只用原生 HTML + JavaScript + Canvas 2D，不要任何外部库、字体文件或图片。

## 讲什么
- 主题：{{大语言模型是大脑，Harness 是手脚}}
- 观众：{{完全不懂技术的人}}
- 一句话结论：{{模型负责想，Harness 负责做}}
- 总时长：30 秒

## 输出契约（必须照做）
1. 只输出一个 html 代码块，不要解释；代码必须完整可运行。
2. canvas 固定 1920×1080，CSS 等比缩放居中，多余部分是黑边。
3. 画面只由 draw(t) 决定；不要 Math.random / Date.now；随机用 mulberry32(seed)。
4. 默认循环；空格暂停；?t=8.5 只显示第 8.5 秒那一帧。

## 画面
- 底色 #FBFAF7；叠几条很淡的灰色擦痕（宽 40–90px，透明度 0.03–0.06）。
- 线条：黑色马克笔 #1B1B1B，宽 10px，lineCap/lineJoin = round。
  每一笔画两遍：第一遍 alpha 0.93；第二遍宽 5.5px、alpha 0.55、偏移 ±1.5px。
- 只用黑 + 一个强调色 #E5432B（标题下划线、箭头、副标题、笔帽）。
- 字体：KaiTi, STKaiti, "Kaiti SC", "Microsoft YaHei", sans-serif，粗体；
  标题 110px，标签 90px，副标题 56px；strokeText + fillText，描边宽 ≈ 字号 3.5%。
- 手绘感：每个点 ±2.5px 抖动，抖动用"点的序号 + 固定种子"，不要每帧重新随机。
- 右下角一支马克笔：黑杆、红帽，长约 330px，斜 55°，笔尖停在当前笔画末端；
  全部画完后滑出画面。

## 五拍（每拍 6 秒）
1. 0–6s 钩子：标题「{{AI 是怎么干活的}}」+ 红色下划线；左边画一个云朵形的"脑"，
   里面几条波浪线；标签「{{大语言模型}}」，副标「{{会想、会说}}」。
2. 6–12s 问题：脑的右边画一个空方框；一个火柴人站在方框里，双手摊开；
   副标「{{但它动不了}}」。
3. 12–18s 转折：一条红色箭头从脑指向方框；箭头旁写「{{指令}}」；
   方框变成一只手（五根手指用圆头线），标签「{{Harness}}」。
4. 18–24s 举例：手下面画三个小图标（日历、文件夹、信封），
   依次标「{{定时}}」「{{读写}}」「{{发送}}」；每个图标 0.3s 弹入。
5. 24–30s 落点：所有元素淡到 35%，画面中央只留一行手写字
   「{{模型负责想，Harness 负责做}}」，红色下划线从左到右画完；静止 1.5s。

## 运动规则
- 每一笔是一个点列表；progress 0→1 决定画到第几个点，ease-in-out，一笔 0.4–1.2s。
- 同一时间只画一笔；画完一笔停 0.15s 再画下一笔。
- 文字在对应图形画完后 0.2s 淡入，上浮 10px。
- 拍与拍之间不要硬切；上一拍的元素保留，作为下一拍的背景（白板是累积的）。

## 不要
渐变、阴影、发光、3D、粒子、复杂配色、满屏文字、镜头晃动、第二个强调色。

## 写完后自己过一遍（不要输出）
- t=0 是不是几乎空白的白板？0.3s 内有没有出现第一笔？
- 每个 t 刷新两次是否完全一致？
- 文字有没有被线或笔压住？有没有出 5% 安全边距？
- 30 秒结束时，结论是否只占一行、能一眼读完？
```
