# 生产规范 · 从画布到成片

> 所有数字以 1920×1080 / 24fps 为基准；竖屏须重新安排构图和安全区，渲染与验收工艺相同。

## 1. 交付规格

| 项 | 标准 | 备注 |
|---|---|---|
| 画幅 | 1920×1080（16:9）或 1080×1920（9:16） | 项目明确要求时再使用 2K/4K |
| 帧率 | 24fps（电影感/品牌）或 30fps（信息流） | 全片统一，不混用 |
| 编码 | H.264 / yuv420p / CRF 18 / `+faststart` | 兼容性最好 |
| 音频 | AAC 48kHz，−14 LUFS，真峰值 ≤ −1 dBTP | 无音频也要明确告知 |
| 时长 | 默认 8s，按用户指定正数秒数制作，可包含 180s 等长片 | 误差 ≤ 1 帧；渲染量随帧数增长 |
| 命名 | `项目名_画幅_版本.mp4` | 例：`biennale_16x9_v3.mp4` |

## 2. 项目结构

```
project/
├── index.html          # 唯一入口，包含舞台 + 场景
├── notes.md            # 主题、beat sheet、色板、字体、变更记录
├── out/
│   ├── video.mp4       # 成片
│   ├── poster.png      # 封面帧
│   └── stills/         # 关键帧
└── audio/              # 可选
```

基础场景无需 `node_modules`、构建工具或框架。图形可全部写入一个 HTML；如需有声离线播放，把音频嵌入 HTML 或随项目交付。渲染器的 `--audio` 仅合成 MP4，不自动修改 HTML。

## 3. 确定性（最重要的一条）

渲染器逐帧调用 `__setTime(t)` 截图，所以：

- **禁止** `Math.random()`、`Date.now()`、`new Date()`、`performance.now()` 出现在场景里。
- **禁止**依赖上一帧状态（`s.lastY = y` 这种累积）；所有位置从 `t` 直接算。
- 随机用 `mulberry32(seed)`，在初始化时生成一次数组，之后只读。
- 粒子用闭式解（位置 = f(t, i)），不要物理积分。
- 不要用 CSS transition/animation；不要用 `setTimeout` 驱动动画。
- 字体必须在 `document.fonts.ready` 之后才画；`stage.html` 已经处理。

自检：同一个 `t` 调两次 `__setTime`，两张图的像素必须一致。

## 4. 舞台与坐标

- 复制 `assets/stage.html` 作为起点；只改 `SCENE` 段。
- 坐标系原点左上，y 向下；所有尺寸按 1920×1080 写死，靠 CSS 缩放适配窗口。
- 安全边距：左右 5%（96px），上下 5%（54px）。标题可以更大，但不要贴边。
- 文字基线用 `textBaseline='alphabetic'`，避免不同浏览器的 middle 差异。
- 需要精确字距时用 `trackedText()` 逐字画，不要依赖 `ctx.letterSpacing`。

## 5. 时间与节奏

先写 beat sheet，再写代码。表里每一行都必须有"秒"和"发生什么"。

| 时间 | 画面 | 声音 | 目的 |
|---|---|---|---|
| 0.00–0.30 | 一个点/一条线出现 | 低频 whoosh | 0.3s 内给信息，绝不黑场 |
| 0.30–1.00 | 主体建立 | 节拍进入 | 让观众知道在看什么 |
| 1.00–2.50 | 第一次变化 | 第一个重音 | 钩子 |
| … | … | … | … |
| 8.50–10.00 | 落版 + 微动 | 收尾音 | 记住一句话 |

规则：
- 24fps 下 1 帧 = 41.67ms；卡点要落在帧边界（`Math.round(t*fps)/fps`）。
- 每 0.5s 至少有一个可见变化；不允许连续 1s 完全静止（除非刻意的"呼吸"）。
- 快慢要有对比：连续快切之后给 0.5–1s 的停顿，让观众有时间理解信息。
- 结尾留 0.8–1.2s 的"落版"，不要切在黑场。

## 6. 运动工艺（把动画十二原则翻译成代码）

| 原则 | 代码里的做法 |
|---|---|
| 预备动作 | 主体出发前反向移动 6–12px，0.1–0.15s |
| 跟随/重叠 | 子元素比父元素晚 0.05–0.12s，用 stagger |
| 挤压拉伸 | 砸下时 `scaleY 0.86 / scaleX 1.12`，0.08s 回弹 |
| 弧线 | 位移不要直线插值，加一个垂直偏移（贝塞尔控制点） |
| 缓动 | 进入 `easeOutCubic`，离开 `easeInCubic`，变形 `easeInOutCubic`；匀速只用于机械/传送带 |
| 次要动作 | 主体停下后，背景/光影再动 0.2s |
| 夸张 | 关键帧的位移/缩放比"物理正确"大 10–20% |
| 舞台感 | 一次只让一个元素成为最高对比；其他降饱和/降亮度 |

禁用：所有元素同一个 ease、同一个时长、同时出现（"PPT 式"）。

## 7. 排版

- 1080p 下的字号：主标题 120–220px；副标题 48–72px；正文 32–40px；注释 ≥ 28px。
- 一行中文 ≤ 18 字（字幕 ≤ 14 字）；超过就拆行或拆句。
- 行高 1.2–1.4；标题字距 −2 到 −6px；全大写小字加 4–8px 字距。
- 中英混排：中文用 `"Noto Sans SC","PingFang SC","Microsoft YaHei"`；衬线用 `"Noto Serif SC","Songti SC",SimSun`；等宽数字用 `"IBM Plex Mono",Consolas`。
- 标点：中文用全角，英文用半角；不要让标点出现在行首。
- 文字必须实测宽度：`ctx.measureText()`；不要目测。
- 文字压在复杂背景上时，加 20–40% 的暗/亮底或阴影，保证对比度 ≥ 4.5:1。

## 8. 颜色与质感

- 一主一强调：主色占 60%，中性 30%，强调 10%；强调色全片只用一个。
- 大面积不要纯黑/纯白：黑用 `#0B0E15`，白用 `#F7F5EF`。
- 质感三件套（按需，不要全上）：
  - 颗粒：`grain()`，透明度 4–10%，缓存一次；
  - 暗角：`vignette()`，强度 0.25–0.5；
  - 纸纹：离屏 canvas 生成 3000–6000 个点，`multiply` 叠加 8–15%。
- 渐变只用于光晕/天空/体积光；不要用渐变做"高级感"按钮。
- 颜色数量：一个画面 ≤ 5 色（含黑白）。

## 9. 构图

- 12 列网格，列宽 140px，沟槽 24px，左右边距 96px。
- 一个画面只讲一件事；主体占画面 30–50%，留白 ≥ 30%。
- 视觉重心放在上三分之一或中心偏上；标题不要和主体抢同一水平线。
- 对比靠大小/明暗/虚实，不靠堆元素。
- 每 2–3 个镜头换一次构图（左/右/中/俯），避免"一直居中"。

## 10. 竖屏（9:16）

- **重排，不是裁切。** 横屏的左右关系改成上下关系；标题在上 1/3，主体在中段，字幕在下 1/5。
- 安全区：顶部 120px、底部 220px（避开平台 UI）；字幕基线 y ≈ 1560。
- 字号：中文 64–76px；一行 ≤ 12 字。
- 竖屏节奏更快：前 0.5s 必须有钩子；每 0.3–0.5s 一个变化。

## 11. 声音（可选，但别忽略）

- 没有音轨也可以交付，但要在 `notes.md` 写明"silent master"。
- 有音乐时：先定 BPM，再把关键动作对齐到拍点（120 BPM = 0.5s/拍）。
- 音效清单：whoosh（转场）、tick（数字）、thud（落版）、riser（加速）、click（UI）。
- 混音：`ffmpeg -i video.mp4 -i music.wav -c:v copy -c:a aac -b:a 192k -af loudnorm=I=-14:TP=-1.0:LRA=11 -shortest out.mp4`
- 版权：只用 CC0/已授权音乐；在 `CREDITS.md` 记录来源。

## 12. 性能

- 每帧重画 5000 个粒子在 1080p 下可能掉帧；用 `globalCompositeOperation='lighter'` 批量画，或降到 2000。
- 纸纹/颗粒/渐变缓存到离屏 canvas；不要每帧生成 `ImageData`。
- 少用 `shadowBlur`（极慢）；用多层半透明圆模拟发光。
- 目标：单帧绘制 < 16ms（本地 Chrome）；渲染时单帧截图 < 1s。

## 13. 渲染与验收

```bash
# 0) 静态检查（先跑，30 秒）
node scripts/check.mjs index.html

# 1) 关键帧（先看静帧，别急着渲染）
node scripts/render.mjs --html index.html --stills 0,1,2.5,4,6 --no-encode --out out/video.mp4

# 2) 成片
node scripts/render.mjs --html index.html --out out/video.mp4 --fps 24 --poster 4

# 3) 加音乐
node scripts/render.mjs --html index.html --out out/video.mp4 --audio audio/bed.wav

# 4) 验收
node scripts/validate.mjs out/video.mp4 --duration 8 --fps 24 --width 1920 --height 1080
```

- 渲染前实际查看 ≥ 3 张静帧（开头/中段/结尾），使用宿主的图片查看工具，不要只看代码。
- 交付前跑 `validate.mjs`；黑帧检测会抓出"首帧黑"和"转场黑"。
- 输出目录不要放临时帧；`--keep-frames` 只在调试时用。

## 14. 常见故障

| 现象 | 原因 | 修法 |
|---|---|---|
| 中文变方块 | 字体没加载/系统无此字体 | 用系统字体栈；`document.fonts.ready` 后再画 |
| 渲染出来比预览模糊 | canvas CSS 被放大 / DPR 不是 1 | canvas 固定 1920×1080，渲染器设 deviceScaleFactor=1 |
| 同一帧两次不一样 | 用了 Math.random / 累积状态 | 改 seeded + 闭式解 |
| 视频卡顿/抖 | 帧率不统一 / 截图尺寸变化 | 固定 fps；渲染器锁定 viewport |
| 首帧黑 | 淡入从 0 开始 | 0s 就给 20–30% 亮度或已有元素 |
| 文字溢出 | 目测宽度 | `measureText` + `wrapText` |
| 颜色发灰 | yuv420p + 低对比 | 提高对比；CRF 16–18 |
| 渲染很慢 | 每帧重画纹理/粒子过多 | 缓存 + 降粒子 + 关 shadowBlur |
