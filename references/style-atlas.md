## 四层怎么配合

```
L1 叙事结构（M）  决定 30 秒里发生什么
L2 视觉皮肤（H/K/Z/R/V）  决定它长什么样
L3 片种/镜头（L/X/O）  决定镜头怎么切、质感怎么来
L4 代码原语（A–G）  决定第一版画面怎么最快跑起来
```

同一个主题可以换任意一层：结构不变换皮肤 = 系列片；皮肤不变换结构 = 同一视觉的不同讲法。

## L1 · 叙事结构 — M（40 条，可用 32 条）

讲法模板：白板、五幕、时间线、一镜到底、破框……决定片子的骨架，不决定长相。

- **M1 白板手绘讲解** — 白底，一只手（或一支笔）一边讲一边画，线条先画出来再上色。　适合：讲概念、讲原理的段落。比如"大语言模型是大脑，Harness 是手脚"。　`★`　→ `library/M_动态风格/M1_白板手绘讲解.md`
- **M2 纸感手写笔记** — 米白纸面，马克笔批注一笔一笔画出来，手写字，大号粗体标题字，偶尔整个画面"啪"一下切到深色。　适合：列要点、讲方法、"你可以这样做"的段落。　`★`　→ `library/M_动态风格/M2_纸感手写笔记.md`
- **M3 文字建筑（口播金句专用）** — 只用文字。每个词有一个"结构上的角色"：有的是梁，有的是柱子，有的是地板。前面的词搭起来，最后一句话"站"在前面搭好的东西上。　适合：结尾金句"学习，相信自己"。全片最值得做的一段。　`★`　→ `library/M_动态风格/M3_文字建筑（口播金句专用）.md`
- **M4 一个元素串全片** — 一个小东西（一个橙色圆点、一个白球）贯穿所有场景：它先是开关，再变成字母上的点，再变成曲线，再变成一个图形，最后回到结尾。　适合：混搭风格时的"线"。比如可以用一个小圆点代表"公告"、代表"想法"，从头跟到尾。　→ `library/M_动态风格/M4_一个元素串全片.md`
- **M5 一镜到底** — 从头到尾不切镜头，每个场景都是从上一个场景里"长"出来的。　适合：讲变化的段落，比如"以前要自己推，现在坐进去它自己走"，一个画面变到另一个画面。　`★`　→ `library/M_动态风格/M5_一镜到底.md`
- **M6 苹果发布会风** — 柔和、白、亮蓝、玻璃质感，镜头从不停在静止画面上切。　适合：展示工具、展示界面的段落。　→ `library/M_动态风格/M6_苹果发布会风.md`
- **M7 极简卡点** — 一个镜头只讲一件事，大量留白，只用一个强调色，每一刀都在重拍上。　适合：节奏快的段落，比如"你每天要整理的表格、你每周要写的周报……"。　→ `library/M_动态风格/M7_极简卡点.md`
- **M8 口播 + 逐字字幕** — 白底，一种字体，字幕跟着说话一个词一个词打出来，配真实的图片，镜头慢慢漂。　适合：全片的主线。有人讲解、口播的片子，字幕必须对上。　→ `library/M_动态风格/M8_口播 + 逐字字幕.md`
- **M9 情绪弧线：混乱、掌控、清晰** — 全片一条弧线。开头画面乱，中间慢慢理顺，最后干干净净落在一句话上。转场靠同一个形状变过去，不硬切。　适合：整期的结构。　→ `library/M_动态风格/M9_情绪弧线：混乱、掌控、清晰.md`
- **M10 把一个抽象概念、一种情绪做成画面** — 没有具体的人和物，用形状、文字、颜色的变化表现一种感觉。　适合：讲恐惧、焦虑、不安、"想太多"这种情绪的段落。　→ `library/M_动态风格/M10_把一个抽象概念、一种情绪做成画面.md`

## 三条使用纪律

1. **先结构后皮肤。** 先定 M 层的讲法，再挑 K/V/H 的长相；反过来会得到"好看但不知道在讲什么"的片子。
2. **一次只借一层。** 借 O33 的黑白办公大厅，不等于借《桃色公寓》的剧情；借 L1 的字幕新闻语法，不等于借蜜蜂的故事。
3. **长文读三遍不如读一节。** L 类文件按 `## 1. Essence` … `## 12. Variation` 分节，做 10 秒片只读 2/3/4/8 节即可。
