# 提示词配方 · 把素材变成可执行的 brief

> 341 条原文大多是"给人看的风格描述"，直接丢给模型会得到"差不多但不对"的片子。
> 下面 5 个配方负责把它翻译成**可验收的生产指令**。所有模板都假设输出是一个完整的 `index.html`。

## 组装公式

```
主题（一句话）
  × 结构（M：讲法）
  × 皮肤（K/Z/H/V/R：长相）
  × 片种/镜头（L/X/O：质感与切法）
  × 原语（A–G：第一版代码）
  = 一条可执行的 brief
```

顺序不能反：**先定讲法，再定长相，最后定镜头**。反过来会得到"很酷但不知道在讲什么"的片子。

---

## 配方 A · LOCKED SPEC（最常用）

适合：标题卡、金句片、10 秒以内的品牌/产品片。特点：把颜色、坐标、时间轴写死，模型没有发挥空间。

```text
你是一位前端动效工程师 + 美术指导。请写一个完整的 index.html：
只用原生 HTML + JavaScript + Canvas 2D，不要任何外部库、字体文件或图片。

## 内容
- 大标题：{{第一行}} / {{第二行，斜体}}
- 副标题：{{一句话，≤ 14 字}}
- 页脚：{{品牌/日期/编号}}
- 总时长：{{8}} 秒，{{1920×1080}}，{{24}} fps

## 输出契约（必须照做）
1. canvas 固定 {{1920×1080}}，CSS 等比缩放居中，多出来的是黑边。
2. 画面只由 draw(t) 决定（t 是秒）；不要用 Math.random / Date.now；
   随机用 mulberry32(seed)，且只在初始化时生成一次。
3. 默认循环；空格暂停；URL 带 ?t=3.2 时只画第 3.2 秒那一帧。
4. 代码必须完整可运行：不要省略号，不要"其余同上"，不要 TODO。

## 颜色（只准用这些）
- 底 {{#F2E9D2}}；纸纹：{{5000 个 1–3px 方点，透明度 0.045–0.095}}，缓存到离屏 canvas，只画一次
- 主色 {{#1D2A68}}；强调色 {{#F6C23E}}（全片只有这一个强调色）
- 线宽 {{1.6–1.8}}px

## 字体
{{Georgia, "Times New Roman", "Noto Serif SC", "Songti SC", serif}}
标题 {{200}}px / 字距 {{-4}}px；页眉 {{26}}px 大写 / 字距 {{6}}px；页脚 {{34}}px

## 版面（坐标按 1920×1080）
- 外框 strokeRect({{64}}, {{64}}, {{1792}}, {{952}})；两条横线 y={{148}} / {{932}}
- 太阳圆心 ({{1380}}, {{470}})，半径 {{250}}；光晕半径 20→{{560}}
- 标题基线 y={{560}} / {{770}}，左对齐 x={{100}}；标题右端不得越过 x={{948}}
- 页眉基线 y={{118}}；页脚基线 y={{980}}

## 时间轴（秒）
| 时间 | 发生什么 | 缓动 |
|---|---|---|
| 0–{{0.8}} | 外框从四角画到中间 | ease-out |
| {{0.4}}–{{1.8}} | 太阳从下方 300px 升起 | ease-out |
| {{1.0}}–{{2.4}} | 两行标题上浮 24px，字距 +20→−4 | ease-out |
| {{2.0}}–{{2.8}} | 页眉页脚淡入 | linear |
| {{2.8}}–{{7.4}} | 刻度环 1°/s 慢转，其余静置微动 | linear |
| {{7.5}}–{{8.0}} | 整体淡出到纸色 | ease-in |

## 不要
渐变色块、阴影、圆角卡片、第二种强调色、无衬线大标题、发光、粒子、3D。

## 写完后自己过一遍（不要输出）
- 全片是否只有 {{#F6C23E}} 一个强调色？
- 标题是否碰到刻度环？
- t=0 是否几乎没有信息？t=总时长−0.1 时是否所有元素都在？
- 同一个 t 刷新两次，画面是否一模一样？
```

**为什么有效**：颜色、坐标、时间轴都是数字；"高级感"被翻译成可检查的约束；模型无法用"差不多"糊弄。

## 配方 B · 标签 → 规格（把一句话皮肤展开）

适合：`K`（38 条）、`Z`（15 条）、`H`（12 条）、`R`（7 条）这类一句话标签。直接写"粉笔黑板风"会得到一张通用插画；必须把 5 个轴补全。

| 轴 | 要回答的问题 | 粉笔黑板（K10）的例子 |
|---|---|---|
| 底色/材质 | 画在什么上？ | 墨绿黑板 `#1E2A24`，细颗粒，边缘有擦痕 |
| 线/笔触 | 什么笔？多粗？抖不抖？ | 白粉笔 6px，双线（实线 + 偏移 1.5px 的半透明），端点为圆头，轻微抖 |
| 色板 | 几种颜色？各自角色？ | 白 `#F2F0E6` 为主；黄 `#F2C14E` 标重点；粉 `#E88C8C` 标错误；最多 3 色 |
| 字体 | 什么字？多大？ | `KaiTi, STKaiti, serif`，标题 120px，正文 64px，手写倾斜 −1° |
| 运动 | 签名动作是什么？ | 粉笔线逐段出现（0.3s/段）+ 结尾用板擦从左擦掉（0.5s） |

补全后写进配方 A 的「颜色/字体/版面/时间轴」，就得到一条可执行规格。

**一句话模板**：
```
把 {{K10 粉笔黑板}} 展开成可执行规格：底色 {{}}、笔触 {{}}、色板 {{}}、字体 {{}}、签名动作 {{}}。
不要出现 {{照片质感/渐变/3D}}；所有元素必须能用 Canvas 2D 画出来。
```

## 配方 C · 借镜头，不借剧情（O 类 98 部）

适合：需要"电影感"但不想要具体故事。O 文件给的是**技法 + 调色 + 招牌镜头 + 剪切节奏**。

```text
读 library/O_奥斯卡98部/{{O33_桃色公寓}}.md，只提取这四样：
1. 技法：{{Saul Bass 式白线在黑底上滑入，搭出一点透视}}
2. 调色：{{黑白灰阶 + 唯一暖色}}
3. 招牌镜头：{{从白线到无尽办公大厅的透视展开}}
4. 剪切节奏：{{每 2–3 秒一刀}}

把这些技法用在一个完全不同的主题上：{{我的主题}}。
不要出现原片的人物、情节、台词、logo；只借镜头语言。
输出 1920×1080 / 24fps / 10 秒，draw(t) 纯函数，颜色不超过 {{3}} 种。
```

**关键句**：`只借镜头语言，不借剧情`。不写这句，模型会把电影剧情也搬进来。

## 配方 D · 压缩风格圣经（L 类 59 条）

L 文件 12KB 左右，有 12 节。不要整篇塞进 prompt，按片子长度选 3–5 节：

| 做多长的片子 | 读哪几节 |
|---|---|
| 6–10 秒片头 | 2 版面、4 字幕/主视觉、8 招牌动作 |
| 15–30 秒 | 1 本质、2 版面、3 剪辑、8 招牌动作 |
| 30–60 秒 | 1、2、3、4、5、8、11 坑 |

```text
读 {{L1_字幕新闻}}.md 的第 {{2/3/4/8}} 节，提炼成一份 20 秒竖屏片子的规格：
- 画面分区（每个区放什么、坐标）
- 字体与字号（中文一行 ≤ {{14}} 字）
- 剪辑节奏（每 {{0.5}} 秒一个动作）
- 3 个招牌动作（必须出现）
- 3 个绝对不能出现的元素

主题：{{}}。把原文件里的"实拍素材"全部替换成程序生成的图形/纹理，
不要引用任何外部视频、图片、字体。
```

**注意**：L 类默认假设有实拍素材、配音、剪辑软件。改写成纯代码时，必须明确"实拍→程序生成"的替换规则，否则模型会写 `video src=...`。

## 配方 E · 代码原语（A–G 26 条）

适合：想 10 分钟内看到第一版动态。A–G 每条都带一个 `S.XX(c,w,h,t,s)` 函数。

```text
读 library/A-G_代码样片/{{A1_字雨}}.md，把其中的绘制函数接进 assets/stage.html：
- 保留原函数的视觉逻辑，不要重写
- 把 PARENT / 字体 / 颜色改成：{{}}
- 时长 {{8}} 秒，24fps，1920×1080
- 加一个 0–0.6s 的淡入和最后 0.5s 的收尾，其余时间保持原节奏
- 输出完整 index.html，draw(t) 纯函数
```

**常见坑**：原文的函数依赖 `_公共函数.js`（`rng / vgrad / glowDot / clamp / easeOut` 等），要么一起复制，要么用 `stage.html` 里的同名工具替换。

## 负面清单（每条 prompt 都该带）

```
不要：模板感、默认 AI 审美、紫色渐变、玻璃拟态卡片、emoji、无意义粒子、
满屏 glow、字体超过 2 种、字号小于 28px、文字贴边、正文超过 3 行、
纯 #000 / #FFF 大面积、匀速运动（除非机械感）、每个元素同时出现。
```

## 自检话术（让模型自己先过一遍）

```
写完后不要解释，先自己检查：
1. 同一 t 渲染两次是否完全一致？
2. 所有文字是否在 5% 安全边距内、没有被遮挡？
3. 第一帧是否在 0.3s 内给出信息？
4. 是否有连续 1s 画面完全静止？
5. 是否只用了规定的颜色/字体/元素？
6. 有没有任何外部依赖？
有问题就改，改完再输出。
```

## 一条完整 brief 的骨架

```
角色 → 主题/受众 → 时长/画幅/fps → 结构（几拍，每拍发生什么）
→ 皮肤（色板/字体/材质/签名动作）→ 版面（坐标/安全区）
→ 时间轴（表）→ 声音（可选）→ 不要 → 自检 → 输出契约
```

缺任何一段，模型都会用默认值补；默认值就是"AI 味"的来源。
