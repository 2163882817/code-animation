# 可选风格资料库

核心公开版本不附带来源与分发权限尚未逐项核验的原文、图片和代码片段。该目录的本地资料保留在维护者设备中；默认 Git 忽略规则与发布脚本不会纳入它们。

原始本地目录包含 341 份 Markdown 条目、193 张 JPG 和一个 JavaScript 文件，其中 8 条只有标题与分类，没有风格正文。这个数字描述本地资料规模，不代表公开版提供了 341 套授权模板。

## 没有资料库也能使用

从 `references/style-stacks.md` 中选一套组合摘要，参考制作规范自行规划原创构图，再按分镜、关键帧、动画、渲染与验收流程制作。不要求联网下载原文，也不要求读取不存在的文件。

`references/style-atlas.md` 保留本地扩展资料的元信息索引，其条目中的原文与预览图路径只有安装相应的已授权资料后才可用。

## 将材料加入公开版本

先记录文件路径、作者或权利人、原始链接、许可证或授权凭据、改写情况与核验日期。确认允许公开分发后，再更新 SOURCES.md、忽略规则和发布文件范围。未知授权状态不能视作允许分发。
